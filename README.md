# ear-training

Browser ear-training drill for relative pitch (solfège degrees 1–7 and high 1).

## Demo

https://sepzok.github.io/ear-training/

## Use

1. Click **播放** (or press Space) to hear the phrase.
2. Enter degrees with the pad or keys `1`–`8`.
3. **批改本题** (Enter) grades the active item; wrong answers reveal the key.
4. Adjust phrase length (1–5 notes), key echo, and piano/beep timbre in settings.

Piano samples live under `assets/piano/`. No build step — open `index.html` or use GitHub Pages from `main`.
